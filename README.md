# Homebrew Tap for Blitz CLI

This is the official Homebrew tap for [Blitz CLI](https://blitzcli.com).

## Installation

```bash
brew tap blitzcli/blitz
brew install blitz
```

## Updating

```bash
brew upgrade blitz
```

## Uninstalling

```bash
brew uninstall blitz
brew untap blitzcli/blitz
```

## About Blitz

Blitz is an AI-powered developer onboarding CLI. Onboard to any codebase in hours, not weeks.

- Website: https://blitzcli.com
- GitHub: https://github.com/modulollc/blitz
